# Phase 09 · Comprehension exam (answer key, Ambrose, 2026-09-11)

Exam-taker rules: a fresh agent that has never seen BeePOS or BeeUI source. It may read ONLY https://beeui.beemvp.com/docs/learn/** , /docs/guides/** , /docs/theming/ , /docs/accessibility/** , /docs/reference/** (not the component pages, not llms files, not this file). It answers in its own words with the URL it used per answer. Time-box: 90 minutes wall clock. Grading: 2 = correct and grounded, 1 = partially right or right but ungrounded, 0 = wrong or "not found". A page "transfers knowledge" when ≥ 80% of the questions drawn from it score 2.

| # | Page | Question (application-style) | Key (must contain) |
|---|---|---|---|
| 1 | learn/foundations | Your team wants to wrap every BeeUI component in a "house" component "just in case". What does the docs say about this, and when is a wrapper justified? | Anti-pattern: duplicates the contract, hides the upgrade path, makes the reference useless; wrapper only when it encodes a genuine product rule. |
| 2 | learn/foundations | Name the three packages in the layer stack and what each owns. Where do Patterns sit relative to your app? | core (engine-neutral utilities, geometry), tokens (semantic color/typography/spacing/density/breakpoints), ui (components, behavior, variants, a11y); Patterns are reference composition above ui, never a runtime dependency. |
| 3 | learn/ownership-model | Your header and content both look pushed down by the status bar on iOS. What rule did you break and what is the fix? | One owner per system edge; SafeArea defaults to all edges, so a nested unqualified SafeArea doubles insets; give each SafeArea explicit edges, exactly one claims top. |
| 4 | learn/ownership-model | You added a global toast store in your state library to "track toasts". Why is that wrong per the docs? | Do not mirror runtime state; BeeUI's toast runtime already owns the queue; two sources of truth and a viewport that disagrees. |
| 5 | learn/composition-model | A colleague moved SelectTrigger into a shared header component and left SelectContent in the screen. It type-checks. What will break? | Parts read context from the root; hoisting breaks anchoring, dismissal arbitration and focus restoration; failure is runtime, not a type error. |
| 6 | learn/composition-model | SelectItem does not look the way you need. Should you write your own item component? What does the docs recommend? | No; put your content inside SelectItem; the a11y semantics and selection reporting live in the part; children is the extension point. |
| 7 | learn/state-model | You pass `checked` to Checkbox without `onCheckedChange`. What happens in dev and in prod? | Control becomes read-only (renders your value, can never change); BeeUI warns in development builds. |
| 8 | learn/state-model | You render `<Dialog open={isOpen}>` without onOpenChange. Is it a runtime bug or a compile error, and why? | Compile error: overlay families type props as a union; supplying open makes onOpenChange required and rejects defaultOpen. |
| 9 | learn/state-model | An Accordion with defaultValue="shipping" is inside a conditionally rendered container. After toggling the container, which item is open and why? | It resets to "shipping": defaultValue is a seed read at mount; remount re-reads it; uncontrolled state does not survive unmount. |
| 10 | learn/overlays-and-runtime | A toast fires with no error but never appears. The docs name one specific cause; what is it? | useToast resolves to the nearest runtime; a nested BeeUIProvider always creates a new toast runtime/viewport, so the toast rendered in a nested viewport that is offscreen/clipped/unmounted. |
| 11 | learn/overlays-and-runtime | A Popover opened inside a Dialog: which element is it positioned against, and which layer does Escape close? | Against the nearest host (the dialog), not the window; Escape closes the deepest active scope (innermost overlay). |
| 12 | learn/overlays-and-runtime | Does nesting a second BeeUIProvider scope overlays? Does it scope toasts? | Overlay runtime yields to the parent (no scoping); toast runtime always creates a new one (scoped). Asymmetry is intentional. |
| 13 | learn/forms-model | You set `error="Enter a valid email"` on Field but the error never shows. Most likely cause per the docs? | invalid was not set to true; Field shows error only when invalid is true and error is a string; otherwise shows description. |
| 14 | learn/forms-model | You put three checkboxes inside one Field to share a label. What is wrong and what should you use? | One control per Field; the accessible name would point at several inputs; use FormGroup with a legend. |
| 15 | learn/forms-model | Which of these does Field do: associate the label, decide when to validate, announce the error, own submission? | Associates label and required state, announces error as polite live region; never validates, never owns submission. |
| 16 | learn/cross-platform-model | Your release was reviewed only from the Web export. Which class of evidence is missing and name two things it alone can prove. | Class 4 simulator/device runtime; proves insets, keyboard avoidance, dismissal/hardware back, assistive technology. |
| 17 | learn/cross-platform-model | Which components have platform-split implementations, and does the split change props or behavior? | Sheet, Tooltip, DatePicker, DateTimePicker, Table's Web surface, portal transport; exported name, props, types and documented behavior stay identical. |
| 18 | learn/responsive-model | How many named breakpoints does BeeUI ship, where do you read them from, and what should you use useWindowDimensions for? | Two: breakpoint.medium and breakpoint.expanded from @beemvp/beeui-tokens; compact is the implicit base; useWindowDimensions only for the structural decision of which subtree renders; CSS variants for cosmetics. |
| 19 | learn/accessibility-model | Under a reduced-motion preference, what must stay and what may reduce? Give the docs' rule. | Decorative animation reduces; state, focus, loading and success/error feedback stay; motion may clarify state, never carry it. |
| 20 | learn/accessibility-model | Who owns text scaling, and what in your code most often breaks it? | The platform (Dynamic Type, browser zoom); BeeUI never disables font scaling and uses rem-based Web typography; your fixed heights around text break it. |
| 21 | guides/density | How do you switch density for the whole app and for one subtree, and does density change the touch-target floor? | Per the density guide's documented API (grader checks against the page); touch target floor never shrinks under any density mode. |
| 22 | guides/table | Who owns sort and selection state in Table, and what does the guide say about virtualization / data grids? | Caller-owned; Table is a composable primitive family, not a data grid; no built-in sorting/virtualization. |
| 23 | guides/date-time | What timezone does DatePicker use and who converts business-calendar rules? | Timezone-free, Intl-driven, single-date value contracts; the app owns timezone/business-calendar conversion. |
| 24 | theming + guides/branding | Where do brand colors live, and may a component use a literal brand color? What component scopes a subtree theme? | Tokens/theme CSS (semantic tokens); never literal brand colors in components; BeeThemeScope. |
| 25 | reference/tokens or learn/responsive | Name the token families that carry layout vocabulary besides breakpoints. | pageGutter, contentWidth, controlSize (touchTarget). |

Scoring sheet: per question 0/1/2, per page average, overall %. Threshold for "docs transfer knowledge": overall ≥ 80% and no page below 60%.
